Оценка задачи в points
В каждую сложность уже заложена база: озвучка (с/без субтитров) + эмодзи + склейка/переходы + стрелка + музыка (выданная). Отмечай только то, что сверх базы.
Отметь пункты, которые есть в задаче.
Калькулятор сложит звёздочки и выдаст сложность с поинтами.

Как считается оценка

Итог = база основной сложности + сумма звёздочек каждого пункта по цене его сложности (без базы). Сумма попадает в диапазон — диапазон и задаёт сложность задачи.

Справка по типам

Определения, на которые опираются формулировки пунктов.

Анимация
Простая
Примитивные анимации из Animation Composer.
Средняя
Навык по position / scale / rotation, 1–2 шага: показали форму → кнопки выбора. Сюда же появляющиеся формы и их заполнение.
Сложная
position / scale / rotation с 3D; сложные 3D-мокапы и шаблоны; либо средняя анимация из 3 и более шагов.
Футажи
Примитивные
Лес, горы, пейзажи, без конкретики; satisfying (залипательные); игровые — паркур Minecraft, раннеры; фотографии (2 фото = 1 видео).
Обычные
Средней сложности, по сюжету озвучки или по теме: разные работы, подписание документов, получение зарплаты, конкретные локационные перелёты.
Сложные
Максимально необычные нативные футажи, поиск занимает много времени. Такие в целях экономии обычно генерируются через AI.
Разговорные генерации
Простые · Low
Есть понятный референс, распространённый сценарий, один объект или персонаж без доп. действий (фон может быть живой), нет сюжетного развития — достаточно адаптировать существующую идею. Сюда же Medium-случай, если есть готовый отработанный промпт.
Обычные · Medium
Есть дополнительное действие (нарезать овощи, упаковать чемодан, езда на велосипеде); есть моушн в генерации — рассказчик говорит, затем камера уводит на другой объект; два человека говорят в одном кадре одной генерацией. Сюда же аватар, созданный через новую нативную фотографию, которую перегенерировали под окружение или профессию, и аватар из новой нативной нестандартной фотографии.
Нестандартная фотография
Человек или селфи с конкретной локацией, профессией и подобным по ТЗ.
Стандартная фотография
Примитивное селфи: без конкретной локации по ТЗ, без конкретной профессии. Аватары из таких фотографий считаются простыми.
Сложные · High
Два человека в одном кадре двумя генерациями (диалог); один человек делает несколько разных действий — например, снимает деньги в банкомате, потом идёт по улице и платит на кассе.
Правила, которые калькулятор не считает автоматически
Пересечение пунктов
Если пункты уже перекрывают друг друга — например, запись экрана входит в «средняя анимация + материалы для нарезки» — младший пункт не учитывается. Конструктор подсвечивает известные пересечения, но финальное решение за оценщиком.
Повтор базы
При комбинировании звёздочек разных уровней база креатива считается один раз — по основной сложности.
Неполный объём
Если вместо 6 обычных разговорных генераций сделано 3 — оценка понижается до Low.
Add-points
Lowest при 5★ — можно запросить доп. 0.5–0.75. Medium при 6★ и при 9★ — доп. 1–1.5. Lowest при 8★ и High при 6★ — индивидуальная переоценка.
Reject
Некорректные тайм-коды — задача возвращается на доработку.
Пять вопросов из методики вместо чтения таблицы. Отвечай по ТЗ — на выходе сложность генераций, поинты и готовый пункт, который остаётся отметить в конструкторе.
